# Module: Norms
`lib/tamanna/norms.ts` holds Appendix IV/V tables as range strings; `stenOf(class, gender, test, raw)` returns Sten 1-10 (first matching range). `bandOf` maps to Low/Average/High. Run `npm run check:norms` after edits. Booklet content for reports is in `lib/tamanna/booklet.ts`; `lib/tamanna/profile.ts` builds the per-student profile.
