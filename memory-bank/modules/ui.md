# Module: UI
Layout: `components/layout/Sidebar` (left menu with non-technical teacher labels, drawer on mobile), `components/layout/TopBar`, `app/admin/layout.tsx`. Shared: `components/ui` (Button, Card with header slots, Badge, StatCard, PageHeader, Input, Select, Skeleton, Dialog), `Toast` (useToast), `CameraCapture`, `VersionBadge`.
Admin content and the landing page use the available viewport width with responsive gutters rather than a narrow fixed max width. The mobile sidebar locks background scrolling while open and keeps overflow scrolling within the menu. The landing page uses a hamburger toggle to expand its mobile section menu; selecting a section closes it. Visible demo indicators use a pulse animation that is disabled for reduced-motion preferences. The login page includes Home links in its top bar and footer.
The dashboard omits scan and print shortcuts and no longer prompts for batch hand checks; demo mode is labeled "Demo Data" in the sidebar.
Dashboard performance charts use level-colored legend pills and bar labels, with student counts listed beneath each bar.
The desktop Student Reports table uses a brand-green header and clear cell borders; it stays horizontally scrollable when needed.
Sidebar surfaces use the Tamanna green palette. Student Reports actions include Report, Profile, OMR Sheet, and delete. There are no hand-check actions.
Admin pages show an icon before each page title. Mobile admin screens have a fixed bottom navigation for Dashboard, Check Sheets, and Student Reports; the Check Sheets action is centered in a raised round button. Dashboard performance charts display in two columns on wider screens.
Show "Uttar Pradesh" beneath the Tamanna logo across the portal and identify Uttar Pradesh in the landing-page programme label.
The landing page omits the former In schools workflow and guide-credit section.
Student Reports has no verified/mismatch/excluded count cards or verification badges. Profile and roll-number buttons open a details-only dialog, without a scorecard or sheet fetch. Review scan / Confirm blurry answers sits under Check and opens originals and editable responses. Marks from clear answers show immediately; blurry sections show provisional marks and unreadable counts, without Sten. Confirm and score saves final marks only after every uncertain answer is corrected. Blurry sections expand automatically.
Dialogs load on demand and share `components/ui/Dialog.tsx` for modal focus, Escape/backdrop closing, and scroll cleanup. In-flight sheet reads abort on close; writes disable closing until completion. Report and print links disable prefetch. Sidebar navigation immediately displays a skeleton while the destination page loads.
Dashboard summary cards span three equal columns on wider screens, matching the full-width card layout on Student Reports. The demo banner reads "Demo Data Mode: showing sample student records."
Routes: `/admin` dashboard, `/admin/results` (student reports and scan correction), `/admin/students/[id]`, `/admin/scan` (check answer sheets), `/admin/key` (answer key), `/admin/logs` (dedicated activity logs with six categories and server pagination), `/admin/settings` (account profile and password). The old `/admin/verify` route redirects to Student Reports.
